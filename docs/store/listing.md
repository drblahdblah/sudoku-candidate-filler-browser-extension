# Store listing copy

## Name

Sudoku Candidate Filler

## Short description

Shows standard pencil-mark candidates for The Age Sudoku puzzles.

## Full description

Sudoku Candidate Filler calculates the valid digits for each empty cell in a
The Age Sudoku puzzle and displays them as pencil marks. It recalculates after
you change the puzzle, start a new one, return to the page, or select the
toolbar action.

The extension works only on `www.theage.com.au/puzzles/sudoku/*`. It provides
standard row, column, and 3×3-box candidates; it does not solve the puzzle,
make network requests, bypass access controls, or modify completed cells.
